¿Qué es RagsMc Launcher?

RagsMc Launcher es un proyecto independiente creado para ofrecer una experiencia moderna y personalizada para jugar Minecraft desde un solo lugar.

Cada sistema, pantalla y decisión está siendo pensado para construir una base sólida, rápida y preparada para crecer junto a la comunidad.

Preguntas frecuentes

¿Tenés dudas?

Resolvemos las preguntas más comunes sobre RagsMc Launcher.

¿Qué es RagsMc Launcher?

RagsMc Launcher es un lanzador de Minecraft independiente, diseñado para ser rápido, simple y con identidad propia. Está hecho por jugadores, para jugadores.

¿Es gratis?

Sí, RagsMc Launcher es completamente gratuito. No hay costos ocultos ni suscripciones obligatorias.

¿En qué sistemas está disponible?

Por ahora para Windows. Linux está en nuestra ruta de desarrollo y llegará próximamente.

¿El launcher recopila mis datos?

No. RagsMc Launcher no recopila ni comparte tus datos personales. Tu privacidad es importante.

¿Cuándo estará disponible para Linux?

Está en nuestra ruta de desarrollo. No hay una fecha exacta todavía, pero es una prioridad.

¿Cómo reporto un bug o sugerencia?

Escríbenos en la sección de comunidad. Ahí nos encontrás activos y listos para ayudar.

¿Puedo usar mis mods existentes?

Sí, el launcher tiene un gestor de mods integrado para activar, desactivar y gestionar tus mods.
