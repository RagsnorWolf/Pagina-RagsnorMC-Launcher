Qué está pasando

Windows SmartScreen, Windows Defender o un antivirus de terceros pueden mostrar una advertencia al ejecutar RagsMC_Launcher_Setup_v1.0.4.exe. En la mayoría de los casos no detectan código malicioso: aplican una regla heurística a instaladores nuevos o poco conocidos.

No ignores una detección real. Si tu antivirus identifica una amenaza con nombre propio, no ejecutes el archivo. Verificá primero el hash SHA-256 y consultalo en VirusTotal. Si no coincide con el publicado acá, descargaste una copia alterada.

Por qué ocurre

01 · NSIS

El instalador usa NSIS

NSIS es un sistema de instalación legítimo y muy usado. También lo usa malware, así que algunos motores marcan todos los instaladores NSIS como sospechosos.

02 · Reputación

Es una versión nueva

El ejecutable todavía no tiene historial de reputación en las bases de antivirus. La ausencia de datos se interpreta como riesgo.

03 · Firma

Sin certificado comercial

No usamos un certificado de firma de código de una CA comercial. SmartScreen trata a cualquier app sin firma como no confiable.

Ninguna de estas tres cosas significa que el archivo sea malicioso. Significa que el instalador no tiene la reputación ni la firma que los filtros automáticos esperan.

Verificá el archivo

El hash SHA-256 es la huella digital del archivo. Si el hash de tu descarga coincide con el publicado, el archivo es exactamente el que distribuimos.

En Windows PowerShell

Get-FileHash .\RagsMC_Launcher_Setup_v1.0.4.exe -Algorithm SHA256

Compará con estos valores

RagsMC_Launcher_Setup_v1.0.4.exe
BA1147665E79190B4470954A839BE95BE9F35D8BBC715012DE62169DB0C4122A
RagsMC_Launcher_Setup_v1.0.4.zip
E7EEB809BDD60156AFB076C54C8DF053C232B0EAE347B5E32255D22786863454

Si el hash no coincide, borrá el archivo y descargalo de nuevo desde este sitio. No lo ejecutes.

Cómo reportar el falso positivo

  1. Agregá una exclusión temporal en tu antivirus solo si el hash coincide. Revisá la configuración de “Exclusiones” o “Archivos permitidos”.
  2. Reportá el falso positivo al fabricante de tu antivirus. Casi todos tienen un formulario de “Report false positive” o “Submit a sample”.
  3. Probá la versión ZIP. Al no ser un instalador NSIS, suele generar menos advertencias. Descomprimila y ejecutá el launcher desde la carpeta.
  4. Contanos qué pasó abriendo un issue en GitHub. Incluí el nombre del antivirus, la versión y el mensaje exacto.

No recomendamos desactivar el antivirus por completo ni agregar exclusiones generales. La exclusión debe apuntar solo al archivo verificado.
